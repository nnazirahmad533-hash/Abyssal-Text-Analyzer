# Abyssal Text Analyzer 🌌

Welcome to the **Abyssal Text Analyzer** project! This is a Python-based text analysis tool that explores the depths of string patterns and text manipulation.

## What Does It Do?

This project analyzes text pairs to detect:
- **Palindrome Patterns** — Identifies if text reads the same forwards and backwards
- **Anagram/Window Matches** — Finds matching character combinations between text segments using sliding-window logic

## Key Features

✨ **String Preprocessing** — Cleans and normalizes text for analysis  
🔤 **Pattern Detection** — Uses `Counter` for efficient character matching  
🎯 **Sliding-Window Logic** — Advanced algorithms for pattern recognition  
⚙️ **Interactive Menu** — User-friendly command-line interface  
🔄 **Function-Based Architecture** — Modular and reusable code structure  

## Quick Start

1. Clone the repository
2. Run the main program
3. Choose an analysis option from the menu
4. Enter your text pairs
5. Get instant results!
